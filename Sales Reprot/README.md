### Sales Report

# Description
Sales Report – an interactive report designed to analyze sales performance through trends and segmentation. As a Power BI solution, it serves as a single, official source of truth for all members of the organization. The report presents sales data from a fictional company, Contoso.

# Tech Stack
 Power BI Desktop – main tool for report creation
 Power Query – data transformation
 MS SQL – data source
 TMDL – mass creation of measures
 PowerPoint – front-end design and layout
 Python script (in Power BI) – implementation of a waterfall chart
 SVG – KPI cards creation

SVG visual elements and the waterfall chart logic were generated with assistance from Claude Code.

# Data Source
Contoso dataset — fictional data created by Microsoft, used by them to present their solutions.
